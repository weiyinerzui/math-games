# 🏃 小羽互动数学课堂

依据**认知负荷理论**与**交替实例原则**设计的互动数学闯关游戏。零依赖、单 HTML 文件、手机/电脑均可玩。

## 追及大冒险（三年级 · 追及问题）

> 题目：甲、乙两人从 A 地到 B 地，甲每小时走 6 千米，乙每小时走 4 千米，乙先走了 8 千米，甲出发后多少小时可以追上乙？

**五关分解（每关只引入一个新概念）：**

| 关 | 目标 | 关键概念 |
|----|------|---------|
| 1️⃣ 谁追得上谁 | 速度差感知 | 快的 − 慢的 |
| 2️⃣ 先出发的「小领先」 | 路程差 | 慢速 × 先行时间 |
| 3️⃣ 每小时追回一点点 | 逐时逼近 | 8→6→4→2→0 |
| 4️⃣ 聪明的算式 | 公式形成 | 路程差 ÷ 速度差 |
| 5️⃣ 完整挑战 | 原题 + 3 个变式 | 三步法综合 |

**交替实例设计**：走路 → 姐妹赛跑 → 龟兔赛跑 → 轿车追卡车 → 哥弟挑战，故事表皮轮换，深层结构（追及三要素）不变。
